# 콩벌레 (`EldenInstantRoll.exe`) v1.1.0

**콩벌레 (EldenInstantRoll)**는 **엘든링: 밤의 통치자 (Elden Ring Nightreign)** 및 **엘든링 본편 (Elden Ring)**에서 선택한 키를 **누르는 즉시 짧은 탭(Tap-on-Press)으로 발동**시켜 주는 Windows 10/11 전용 경량 단일 실행 파일(`.exe`) 프로그램입니다. (닿자마자 굴러버리는 콩벌레 컨셉!)

> 엘든링 계열 게임은 구르기/대시 키가 공용이라 기본적으로 키를 **뗄 때** 구르기가 발동합니다. 이 프로그램은 체크된 키를 **누르는 순간** 짧은 스캔코드 입력(`KEY_DOWN → 25ms → KEY_UP`)을 즉시 전송하여 반응 속도를 크게 개선합니다.

---

## v1.1.0 주요 기능

### 1. 엘밤통 핵심 7개 액션 키 목록 & 다중 즉시 발동 선택
리매핑 없이 엘밤통의 핵심 7개 액션을 기본 제공하며, 원하는 키만 여러 개 체크하여 누름 즉시 발동으로 사용할 수 있습니다.

| 액션 | 기본 키 (엘밤통 표준) | 기본 체크 |
|---|---|---|
| **구르기** | `Left Shift` (`sc02A`) | **ON** |
| **달리기 (질주)** | `Left Alt` (`sc038`) | OFF |
| **스킬** | `E` (`sc012`) | OFF |
| **아츠** | `R` (`sc013`) | OFF |
| **성배병** | `1` (`sc002`) | OFF |
| **아이템 사용** | `G` (`sc022`) | OFF |
| **아이템 변경** | `2` (`sc003`) | OFF |

- **체크된 키만** 누름 즉시 발동으로 후킹하며, **체크 해제된 키는 원본 입력을 100% 그대로 통과**시킵니다.
- 차징·홀드가 필요한 키는 UI에서 1클릭으로 체크 해제할 수 있습니다.
- 각 액션의 키를 키보드/마우스(`MouseLeft`, `MouseRight`, `MouseMiddle`, `Mouse4`, `Mouse5`)로 직접 변경·해제할 수 있으며, **`+ 키 추가`**(사용자 키 추가/삭제) 및 **`기본값 초기화`**를 지원합니다.

### 2. 한/영 무관 스캔코드 엔진 & 조건부 마우스 후크
- **하드웨어 스캔코드(`KEYEVENTF_SCANCODE`) 기반**으로 동작하므로 한글/영문(IME) 상태와 무관하게 100% 동일하게 작동합니다.
- 여러 키를 동시에 체크해도 **키별 독립 `held` 상태**로 관리되어 간섭이나 자동 반복(2연속 발동)이 발생하지 않습니다.
- 체크된 항목 중 **마우스 버튼이 하나도 없을 때는 `WH_MOUSE_LL`을 설치하지 않아** 1000Hz/8000Hz 게이밍 마우스에 지연(0ms)을 주지 않습니다.
- 마스터 토글 단축키(`F8` 등) 또는 이미 체크된 다른 액션과 물리 키가 겹치는 경우 자동으로 충돌을 방지합니다.

### 3. 최우선 마스터 ON/OFF 우선순위 제어
- 글로벌 단축키(기본 `F8`, 변경 가능) 또는 상단 마스터 스위치로 게임 중에도 즉시 ON/OFF 전환 가능합니다.
- **마스터가 OFF가 되면**:
  1. 모든 키의 즉시 발동 후킹이 완전히 중지됩니다.
  2. 하위 **게임 감지 자동 켜짐** 및 **윈도우 부팅 시 자동 실행** 토글이 **둘 다 자동으로 OFF 전환 + 비활성화(클릭 불가)** 됩니다.
  3. 등록되어 있던 Windows 시작프로그램 레지스트리(`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\EldenInstantRoll`)도 **즉시 삭제**됩니다.
- **마스터가 ON일 때만** 하위 두 토글을 개별적으로 자유롭게 제어할 수 있습니다.

### 4. 완전 독립 실행, 포터블 INI & v1.0.0 자동 마이그레이션
- Windows 10/11 기본 내장 .NET Framework 4.8만 사용하므로 별도 런타임이나 AutoHotkey 설치 없이 **`EldenInstantRoll.exe` 파일 하나만** 실행하면 바로 작동합니다.
- `.exe`와 같은 폴더에 `EldenInstantRoll.ini`로 설정을 자동 저장하며(쓰기 권한 없는 폴더일 경우 `%AppData%\EldenInstantRoll\`로 자동 폴백), 기존 v1.0.0 설정 파일이 있으면 기존 구르기 키를 자동으로 v1.1.0 포맷으로 승격합니다.
- `--minimized` 인자로 시스템 트레이에 조용히 시작할 수 있으며, 중복 실행 시 기존 창이 앞으로 활성화됩니다.

## 다른 Windows 사용자에게 배포하는 방법

1. 빌드된 **`EldenInstantRoll.exe` 파일 하나만** 상대방에게 전달(복사/공유)하면 됩니다.
2. 별도 DLL, AutoHotkey, .NET 설치가 필요 없습니다.
3. 받은 사용자는 원하는 폴더(예: `C:\Tools\EldenInstantRoll\`)에 `EldenInstantRoll.exe`를 두고 더블 클릭하면 바로 실행됩니다.

---

## 관리자 권한 실행이 필요한 경우

- 일반적으로 Steam에서 실행한 엘든링/밤의 통치자는 일반 권한으로 동작하므로 `EldenInstantRoll.exe`도 **일반 권한**으로 바로 작동합니다.
- 만약 게임(또는 Steam/런처)을 **관리자 권한으로 실행**하는 환경이라면, Windows UIPI 보안 정책 때문에 일반 권한 프로그램의 키 입력이 게임에 전달되지 않습니다. 이 경우 `EldenInstantRoll.exe`를 **우클릭 → 관리자 권한으로 실행**해 주세요.

## 빌드 및 테스트 방법

Windows 10/11에 기본 포함된 `csc.exe`(.NET Framework 4.8)로 별도 Visual Studio나 SDK 없이 바로 빌드할 수 있습니다.

```powershell
# 단일 EldenInstantRoll.exe 빌드 (출력: dist\EldenInstantRoll.exe)
.\build.ps1

# 다중 키 필터링 / 마우스 후크 조건부 설치 / 충돌 방지 / v1.0.0 마이그레이션 / 마스터 OFF 규칙 테스트
.\tests\RunTests.ps1
```
