# 콩벌레 (`EldenInstantRoll.exe`)

**콩벌레 (EldenInstantRoll)**는 **엘든링: 밤의 통치자 (Elden Ring Nightreign)** 및 **엘든링 본편 (Elden Ring)**에서 구르기 키를 **누르는 즉시 구르기가 발동**되도록 만들어 주는 Windows 10/11 전용 경량 단일 실행 파일(`.exe`) 프로그램입니다. (닿자마자 굴러버리는 콩벌레 컨셉!)

> 엘든링 계열 게임은 구르기/대시 키가 공용이라 기본적으로 키를 **뗄 때** 구르기가 발동합니다. 이 프로그램은 구르기 키를 **누르는 순간** 짧은 스캔코드 입력(`KEY_DOWN → 25ms → KEY_UP`)을 즉시 전송하여 반응 속도를 크게 개선합니다.

---

## 주요 기능

- **완전 독립 실행 단일 `.exe`**: Windows 10/11 기본 내장 .NET Framework 4.8만 사용하므로 별도 런타임이나 AutoHotkey 설치 없이 `EldenInstantRoll.exe` 하나만 실행하면 바로 작동합니다.
- **한/영 입력기(IME) 무관 스캔코드 엔진**: 하드웨어 스캔코드(`KEYEVENTF_SCANCODE`) 기반으로 동작하므로 한글/영문 상태와 관계없이 100% 동일하게 작동합니다.
- **달리기·이동 중 구르기 지원**: `Shift`, `W/A/S/D`, `Ctrl`, `Alt` 등 다른 키를 누른 채로 구르기 키를 눌러도 자연스럽게 작동하며, 키를 꾹 누르고 있어도 자동 반복(2연속 구르기)이 발생하지 않습니다.
- **키보드 및 마우스 사이드 버튼 지원**: 키보드 아무 키(기본 `Q`)뿐만 아니라 `Mouse4`, `Mouse5`, `휠 클릭(Middle)`도 구르기 키로 지정할 수 있습니다. (키보드 키 사용 시에는 마우스 후크를 설치하지 않아 고폴링레이트 게이밍 마우스에 지연이 전혀 없습니다.)
- **최우선 마스터 ON/OFF 우선순위 제어**:
  - 글로벌 단축키(기본 `F8`, 변경 가능) 또는 상단 마스터 스위치로 게임 중에도 즉시 ON/OFF 가능합니다.
  - **마스터가 OFF가 되면**:
    1. 즉시 구르기 후킹이 완전히 중지됩니다.
    2. 하위 **게임 감지 자동 켜짐** 및 **윈도우 부팅 시 자동 실행** 토글이 **둘 다 자동으로 OFF 전환 + 비활성화(클릭 불가)** 됩니다.
    3. 등록되어 있던 Windows 시작프로그램 레지스트리(`HKCU\Software\Microsoft\Windows\CurrentVersion\Run\EldenInstantRoll`)도 **즉시 삭제**됩니다.
  - **마스터가 ON일 때만** 하위 두 토글을 자유롭게 켜고 끌 수 있습니다.
- **대상 게임 자동 감지 / 수동 모드**:
  - `게임 감지 자동 켜짐` ON: 선택한 게임(`nightreign.exe`, `eldenring.exe`, 추가 프로세스)이 활성 창일 때만 자동 작동하고, 채팅/브라우저로 전환하면 자동 대기(`게임 대기 중`)합니다.
  - `게임 감지 자동 켜짐` OFF: 게임 감지 없이 마스터 ON 상태에서 즉시 작동합니다(메모장 테스트나 기타 게임 테스트에 유용).
- **포터블 설정 저장 & 시스템 트레이**:
  - `.exe`와 같은 폴더에 `EldenInstantRoll.ini`로 설정을 자동 저장합니다(쓰기 권한이 없는 폴더일 경우 `%AppData%\EldenInstantRoll\`로 자동 폴백).
  - `--minimized` 실행 인자로 트레이에서 조용히 시작할 수 있으며, 중복 실행 시 기존 창이 앞으로 활성화됩니다.

## 다른 Windows 사용자에게 배포하는 방법

1. 빌드된 **`EldenInstantRoll.exe` 파일 하나만** 상대방에게 전달(복사/공유)하면 됩니다.
2. 별도 DLL, AutoHotkey, .NET 설치가 필요 없습니다(Windows 10/11 기본 내장 런타임 사용).
3. 받은 사용자는 원하는 폴더에 `EldenInstantRoll.exe`를 두고 더블 클릭해 실행하면 같은 폴더에 `EldenInstantRoll.ini`가 자동 생성됩니다.

## 관리자 권한 실행이 필요한 경우

- 일반적으로 Steam에서 실행한 엘든링/밤의 통치자는 일반 권한으로 동작하므로 `EldenInstantRoll.exe`도 **일반 권한**으로 바로 작동합니다.
- 만약 게임(또는 Steam/런처)을 **관리자 권한으로 실행**하는 환경이라면, Windows UIPI 보안 정책 때문에 일반 권한 프로그램의 키 입력이 게임에 전달되지 않습니다. 이 경우 `EldenInstantRoll.exe`를 **우클릭 → 관리자 권한으로 실행**해 주세요.

## 빌드 및 테스트 방법

Windows 10/11에 기본 포함된 `csc.exe`(.NET Framework 4.8)로 별도 Visual Studio나 SDK 없이 바로 빌드할 수 있습니다.

```powershell
# 단일 EldenInstantRoll.exe 빌드 (출력: dist\EldenInstantRoll.exe)
.\build.ps1

# 핵심 상태 머신 / 우선순위 규칙 / 레지스트리 / INI 자동화 테스트 실행
.\tests\RunTests.ps1
```
